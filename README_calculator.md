# Simple Calculator

A lightweight, interactive command-line calculator written in Python.

## Features
- **Operations Supported**:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`) with divide-by-zero protection
  - Exponentiation / Power (`^`)
- Interactive CLI prompt with input validation.
- Unit test suite included.

## Usage

Run the calculator:
```bash
python3 calculator.py
```

Run unit tests:
```bash
python3 -m unittest test_calculator.py
```
